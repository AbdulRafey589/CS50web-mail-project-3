# CS50 Web – Project 3: Mail

A front-end email application built using **JavaScript, Django, HTML, and CSS** as part of Harvard's CS50 Web Programming with Python and JavaScript.

The application allows users to send, receive, view, archive, and reply to emails through a dynamic interface without requiring page reloads.

## Features

- **Compose & Send:** Send emails to one or multiple recipients with a subject and message body.
- **Mailbox Navigation:** View Inbox, Sent, and Archived emails.
- **View Emails:** Open individual emails and view sender, recipients, subject, timestamp, and message body.
- **Read & Unread Status:** Automatically mark emails as read when opened, with visual indicators for read and unread messages.
- **Archive & Unarchive:** Archive emails from the Inbox and restore them from the Archive mailbox.
- **Reply:** Reply to existing emails with the recipient, subject, and original message automatically prefilled.

## Technologies Used

- **JavaScript** – DOM manipulation, event handling, asynchronous requests, and dynamic UI updates.
- **Python / Django** – Backend application and API.
- **HTML5** – Application structure.
- **CSS3 / Bootstrap** – Styling and responsive interface.
- **Fetch API** – Communication between the frontend and backend.
- **JSON** – Data exchange with the API.

## Key Concepts Practiced

- DOM manipulation using `document.createElement()`, `append()`, and `insertBefore()`.
- Event listeners for dynamically generated elements.
- Working with asynchronous JavaScript and Promises using `.then()`.
- Making GET, POST, and PUT requests using the Fetch API.
- Sending and receiving JSON data.
- Managing application state through backend API updates.
- Using conditional rendering to display different actions based on the selected mailbox.
- Working with template literals and JavaScript string methods.
- Separating data updates from UI rendering.

## What I Learned

This project helped me develop a deeper understanding of JavaScript beyond basic syntax.

I learned how frontend applications communicate with a backend, how to dynamically manipulate the DOM, and how to update the interface based on changes in persistent data.

One of the most valuable aspects was implementing features such as read/unread status, archiving, and replying while understanding the logic behind each interaction.

It also taught me that building an application isn't just about making its features work. **User experience matters too** — from button placement to navigation and making common actions intuitive.
